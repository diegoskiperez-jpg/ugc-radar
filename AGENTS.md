# UGC Radar - Project Instructions

## Project goal
Build a YouTube trending tracker using Python and AWS, following the 8-week project brief.

## Learning rules
- Explain new services and code in beginner-friendly language.
- Do not merge or keep code that the student cannot explain.
- Type and understand core project files rather than blindly copying them.
- For every change, be able to state what it does and how to test it.
- Keep secrets, API keys, passwords, and local environment files out of Git.

## Development expectations
- Use Python 3.12.
- Prefer small, readable functions and clear variable names.
- Add or update tests when behavior changes.
- Document important decisions and weekly learning in STACK_MAP.md and LEARNING.md.
